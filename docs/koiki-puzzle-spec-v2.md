# お料理できるかな！！ v2 仕様書

更新日: 2026-08-31
状態: ローカル実装済み・確認待ち
実装ページ: `koiki-puzzle-v2.html`
サバイバル（旧式）ページ: `koiki-puzzle.html`
サバイバル（旧式）仕様: `docs/koiki-puzzle-spec.md`

## 1. ゲームの目的

開始時に3モードから選択する。

- とことん: 無期限・21食ごとにFB上昇・記録に挑戦
- ノーマル: 1週間・必要食材70%・スキル＋1手
- EX: 1週間・必要食材100%・スキル＋2手

ノーマル・EXは1日3食、7日間、合計21食限定の週間スコアアタックとする。21食目の完成で終了し、週間エナジーを競う。とことんは現行版に近い無期限プレイを維持する。

全モードで料理の自動完成を行わない。必要食材がそろった後も、プレイヤーが料理タイミングと食材バッグから加える食材を選べる。

## 2. データの正本

- 食材19種類: `js/data/foods.js`
- 料理78種類、カテゴリ、本家の必要食材、料理基礎エナジー: `js/data/dishes.js`
- レシピレベルボーナス: `recipeLevelBonusList`
- 食材画像: `img/foods/svg/`

料理カテゴリはサラダ・カレー・デザートの3種類とする。`ずっしりカボチャ`または`おいしいシッポ`を必要とする料理は、通常料理の0.5倍の抽選重みとする。

## 3. モードと保存の単位

サバイバル（旧式）はv2のモードに含めず、別ページ・別ランタイムとして固定する。v2の変更をサバイバルへ自動反映せず、サバイバルの変更もv2へ混ぜない。画面上は相互リンクだけを設ける。

途中セーブは全モード共通で1ゲーム分だけ保持する。ゲーム途中で別モードを選ぶと、終了確認を表示する。確認した場合だけ元のゲームを終了してリザルトを表示し、選択したモードを最初から開始する。キャンセルした場合は現在のゲームをそのまま継続する。

- 再開できるゲームは常に1件
- 保存中のゲームを別モードへ変換しない
- 食材バッグや進行を別モードへ持ち込まない
- 自己ベストはモード別に保存

## 4. 共通ルール

### 4.1 盤面

- 6列×6行の36マス
- 食材35個と操作アイコン1個
- 盤面に出す食材は6種類
- 現在料理の必須食材を盤面候補へ必ず含める
- 同じ食材が縦または横に4個以上並ぶと消える
- 消えた列だけ下へ落ち、新しい食材を補充する
- 盤面が安定するまで連鎖を処理する
- 自動まぜまぜは行わない

#### 新規食材の抽選ウェイト

ゲーム開始時・次の料理への切り替え時・手動まぜまぜ時を「盤面リセット」とする。盤面リセットでは、食材バッグに対する料理の不足数を使う。

```text
不足数 = max(0, 料理の必要数 - 食材バッグ在庫)
ウェイト = max(1, ceil(不足数 / 不足数合計 × 8))
```

不足食材がない場合は必要食材から1種類をランダムに選び、その盤面生成中だけ仮想不足食材（ウェイト8）とする。それ以外はウェイト1とする。仮想不足食材は保存せず、手動まぜまぜごとに選び直す。同じ盤面生成内のリトライでは選び直さない。

食材消去後と連鎖中の補充では仮想不足を使わない。不要食材をウェイト1、必要食材を最低ウェイト2とする。不足がある必要食材には次のウェイトを適用し、不足がない場合は必要食材をすべてウェイト2とする。

```text
必要食材のウェイト = max(2, ceil(不足数 / 不足数合計 × 8))
```

上記は新規食材の抽選ウェイトだけに適用し、食材6種類・必須食材の包含・初期4個消しの禁止・全6種類の出現・有効手の存在条件は変更しない。

### 4.2 手数

- 最大12手
- ゲーム開始時12手
- 食材との入れ替えで1手消費
- 料理完成で5手回復
- 料理ごとに、まぜまぜの初回1回は無料
- とことん・ノーマルは同じ料理の2回目以降、1手消費
- EXは同じ料理で `0 → 1 → 2 → 2…` 手を消費
- 回復後も12手を超えない

食材ゲットと料理チャンスを「スキル」とする。スキル1回の発動ごとの回復量は以下とする。

| モード | 回復 |
| --- | ---: |
| とことん | ＋1手 |
| ノーマル | ＋1手 |
| EX | ＋2手 |

大消しの個数や連鎖数に応じた別枠の手数ボーナスは設けない。同じ1手の中で複数のスキルが発動した場合は、それぞれ回復する。

必要食材が完成していれば残り0手でも料理を作れる。必要食材が未完成のまま0手になるとゲーム終了とする。0手で料理可能な場合は盤面操作とまぜまぜを止め、「料理を作る」だけを許可する。

### 4.3 1手終了時の判定順

1. 盤面消去・連鎖・食材ゲット・料理チャンスを最後まで処理する
2. 必要食材が完成済みなら、0手でも料理待ち状態へ進む
3. 必要食材が未完成かつ0手ならゲーム終了
4. ノーマル・EXで食材バッグが800個を超えたら、超過分を追加食材へ自動投入する
5. 上記以外は次の盤面操作を許可する

## 5. 料理を作る

必要食材がそろっても料理を自動完成させず、「料理を作る」ボタンを有効にする。手数が残っていれば、料理可能になった後も盤面消去・食材ゲット・料理チャンス・食材バッグの調整を続けられる。

### 5.1 食材バッグ

- 盤面消去と食材ゲットで得た食材は食材バッグへ入れる
- 料理の必要食材も任意の追加分も、すべて食材バッグから使用する
- 必要数はロック状態に関係なく使用できる
- 追加分は「投入」から種類と数量を選ぶ
- 料理を作る前なら追加分を食材バッグへ戻せる
- ロック解除だけでは追加食材にせず、明示的に投入した分だけを料理へ加える
- 食材ゲットによる800個超過分は、現在の料理へ使う食材として扱う

### 5.2 ロック

- 食材種類ごとにロック・解除できる
- 新しく食材バッグへ入った種類は全モード共通でロック状態から始める
- プレイヤーが解除した種類は、その後に同じ食材を獲得しても解除状態を維持する
- 「全ロック」で現在の食材バッグを一括ロックできる
- 一括解除は設けない
- ロックは必要数を超えた食材だけを保護する
- 全食材がロック中でも必要数を満たせば料理できる

## 6. エナジー計算

独自の大鍋倍率・一点盛り倍率は使用しない。とことんだけFBボーナスを適用し、ノーマル・EXには適用しない。

```text
レシピLv適用後の料理エナジー
＋ 食材バッグから追加した食材エナジー
↓
とことんだけFBボーナスを適用して切り捨て
↓
通常×1・大成功×2・超成功×3
```

大成功・超成功の倍率は最後に適用する。

### 6.1 レシピレベル

v2全モードで、料理完成時の最終エナジーをレシピLv累計へそのまま加算する。レベルアップ判定は料理完成後に行い、新しいLvのボーナスは次の料理から適用する。

```text
LvN → LvN+1 の必要エナジー = 500 + 4 × N²
LvN到達の累計エナジー = Σ(500 + 4 × n²), n = 1〜N-1
```

- 加算対象はレシピLvボーナス・追加食材・大成功2倍・超成功3倍を含む最終値
- とことんはFB適用後の最終値を加算
- Lv上限は70。Lv70はMAX表示
- 上部のレシピレベルから詳細を開ける
- 詳細には現在Lv、累計、次のLvまでの残量、Lv1〜70のボーナス・必要エナジー・累計を表示
- 到達済み・現在Lv・次のLvを区別し、現在Lvへ自動スクロールする

## 7. 週間ルール

ノーマル・EXだけに適用する。

- 1日3食（朝・昼・晩）
- 7日間で21食
- 21食目の完成でゲーム終了
- 開始時に料理カテゴリを1つ抽選し、21食すべて同じカテゴリ
- 最初の料理は必要食材1種類の料理
- 月曜の2〜3食目は本家必要食材合計30個以下の料理から抽選
- 火曜〜土曜は大皿を含む全料理を通常候補とし、大皿を避ける選出調整は行わない
- 日曜の19〜21食目は今週カテゴリ内の本家必要食材合計TOP5から抽選
- カボチャ・しっぽ料理の0.5倍は月〜土だけ適用し、日曜TOP5内は全料理を同じ重みで抽選
- 次週カテゴリは設けず、ノーマル・EXにはFBボーナスを適用しない

| 食数 | 表示 |
| --- | --- |
| 1〜3食目 | 月曜 朝・昼・晩 |
| 4〜6食目 | 火曜 朝・昼・晩 |
| 19〜21食目 | 日曜 朝・昼・晩 |

### 7.1 日曜日

19〜21食目は日曜日ボーナスを適用する。

- 料理は今週カテゴリ内の本家必要食材合計TOP5から抽選
- 必要食材合計が同じ場合は料理エナジーが高い料理を上位とする
- TOP5内ではカボチャ・しっぽ料理を含め、全料理を同じ確率で抽選する
- 基本成功確率10%
- 日曜日ボーナス＋20ポイント
- 料理チャンス追加確率も加算
- 成功確率は最大100%
- 成功時は大成功ではなく超成功
- 完成料理エナジーは3倍
- 超成功後は料理チャンス追加確率を0%へ戻す

## 8. 料理チャンス

- 1回の盤面解決で2連鎖目以降、連鎖するたびに発動
- 発動1回につき成功確率＋10ポイント
- 発動ポップアップは現在の累計値に関係なく、毎回「料理チャンス発動！ 大成功＋10%」と表示する
- 画面上部の料理チャンスメーターは累計追加確率を「＋30%」のように表示する
- 追加確率上限＋70%
- 大成功または超成功するまで次の料理へ持ち越す
- 成功後は＋0%へ戻す
- ＋70%到達後も発動演出とモード別の手数回復を継続

4連鎖では2・3・4連鎖目の合計3回発動する。ノーマルは成功確率＋30%・合計＋3手、EXは成功確率＋30%・合計＋6手となる。

## 9. 食材ゲット

- 1回の盤面解決で6個以上同時に消すと発動
- 全19食材から3種類を重複なしで抽選
- 取得数を3種類へ可能な限り均等に配分
- 発動ごとにモード別の手数を回復
- ゲーム中の発動回数を累積

| Lv | 取得数 |
| --- | ---: |
| Lv1 | 6個 |
| Lv2 | 8個 |
| Lv3 | 11個 |
| Lv4 | 14個 |
| Lv5 | 17個 |
| Lv6 | 21個 |
| Lv7以降 | 24個 |

## 10. モード別ルール

### 10.1 とことん

- 無期限プレイ
- 現行版の縮小レシピを使用
- 食材バッグ上限なし
- バッグ満杯状態なし
- 全カテゴリの料理から抽選
- 1品目は必要食材1種類の料理
- 食材ゲット・料理チャンスは発動1回につき＋1手
- 開始時はFB＋0%
- 21食完成ごとにFBを＋5ポイントし、次の料理から適用
- FB上限は＋85%
- レシピレベル上限Lv70
- レシピLvボーナスはLv70で固定
- 必要食材数はレシピLvと独立し、料理完成数に応じて増加し続ける

### 10.2 ノーマル

- 21食限定
- 食材バッグ上限800個
- 各料理の本家必要食材数へ70%を掛け、食材ごとに小数点以下を切り上げる
- 食材ゲット・料理チャンスは発動1回につき＋1手
- 週間共通の月曜制限以外に、レシピLvによる段階解放を設けない

### 10.3 EX

- 21食限定
- 食材バッグ上限800個
- 本家の必要食材数を100%使用
- 食材ゲット・料理チャンスは発動1回につき＋2手
- レシピLvによる必要数の段階緩和を設けない

## 11. 食材バッグ上限と自動投入

ノーマル・EXだけに適用する。

- 盤面消去と食材ゲットの取得処理は途中で止めない
- 食材バッグが800個に達しても盤面とまぜまぜを止めない
- 800個を超えた分だけ、現在の料理の追加食材へ自動投入する
- 料理の必要数は自動投入せずバッグに残す
- ロックしていない余剰食材を優先し、同条件なら食材エナジーが低い順に自動投入する
- 全余剰食材がロック済みの場合だけ、ロック済み余剰を低エナジー順に自動投入する
- 手動で追加食材をバッグへ戻して800個を超えた場合も、同じ優先順で再調整する

## 12. 料理カテゴリ

ノーマル・EXではゲーム開始時にサラダ・カレー・デザートから同確率で1カテゴリを抽選し、21食すべてをそのカテゴリから出題する。食材ゲットの抽選はカテゴリに限定しない。

とことんはカテゴリを限定しない。

### 13.3 モード選択UI


- モード

- 完成した食数
- 週間エナジー（とことんは累計エナジー）
- 到達FB（とことん）
- 最大料理エナジー
- 最大連鎖数
- 使用した食材の合計と内訳
- 獲得した食材の合計と内訳
- 自己ベスト更新の有無

Xシェアもモード・カテゴリ・完成食数・エナジーを重複なく表示する。

## 15. セーブ・記録

### 15.1 途中セーブ

- 操作後の安定状態を都度保存する
- モード、盤面、手数、料理、食材バッグ、ロック、料理への追加食材を保存する
- 完成食数、累計エナジー、今週カテゴリ、料理チャンス確率、使用・獲得食材を保存する
- とことんのFBは保存した完成食数から復元する
- 自動投入後の食材バッグと料理への追加食材を保存する
- ゲーム終了時に途中セーブを削除する

### 15.2 既存v2からの移行

既存v2のモード別途中セーブが複数ある場合は、`savedAt`が最も新しい1件だけを共通途中セーブへ一度だけ移行する。旧データは復旧用に削除しない。

サバイバルv1の途中セーブと自己ベストは移行しない。サバイバルページのv1保存領域へ残し、とことんの途中セーブ・自己ベストとは完全に分離する。

### 15.3 モード別記録

- 最高エナジー（ノーマル・EXは週間、とことんは累計）
- 1回の最大料理エナジー
- 最大連鎖数
- 最大レシピレベル
- 最大獲得食材数と内訳
- 最高完成食数

### 15.4 ローカルデバッグ

`file:`またはlocalhostでURLへ`?debug=1`を付けた場合だけ、手数、必要食材、食材バッグ、スキル発動、成功確率、日曜日・21食目への移動、ゲーム終了を操作できるデバッグパネルを表示する。デバッグ操作は現在のローカル途中セーブへ反映する。GitHub Pagesなど公開ホストでは、`?debug=1`を付けても表示・有効化しない。

## 16. 確認条件

- ゲーム開始前に短い説明で3モードを選べる
- サバイバルを別ページで開け、サバイバルv1とv2のランタイム・途中セーブ・自己ベストが混ざらない
- とことんは無期限、ノーマル・EXは21食目で終了する
- ノーマルは本家必要数70%切り上げ、EXは100%になる
- 最初の料理だけ必要食材1種類になる
- ノーマル・EXのカテゴリが開始時に決まり、21食中に変わらない
- 必要食材完成時に自動調理されない
- 0手でも必要食材完成済みなら料理でき、未完成なら終了する
- 全食材ロック中でもバッグ在庫が必要数以上なら料理できる
- 新規取得した食材種類がロック状態になり、解除済みの既存種類は再ロックされない
- ロック解除だけでは余剰食材を消費せず、「投入」で選んだ食材だけが追加食材になる
- 新規開始・途中再開でモード別ルールが表示され、「もう見ない」がモード単位で保存される
- 食材ゲットLvはLv7を上限とする背景メーター、曜日・食事は21食を1周とする背景メーターで進行が分かる
- 食材バッグはノーマル・EXで800個に対する容量を背景メーター表示し、各メーターは低彩度の同系色に統一する
- 全モードでまぜまぜは料理ごとに初回1回だけ無料になる
- EXの2回目は1手、3回目以降は2手を消費する
- 食材ゲットと料理チャンスが、とことん・ノーマルで＋1手、EXで＋2手になる
- 大消し個数・連鎖数による別枠の手数回復がない
- 料理チャンスが2連鎖目以降の毎連鎖で発動し、＋70%でも演出と回復が続く
- 日曜日19〜21食目の成功だけが超成功3倍になる
- とことんのFBが21食ごとに5ポイント上がり、85%で止まる
- ノーマル・EXにはFBボーナスがなく、全モードに次週カテゴリが存在しない
- バッグ800個でも盤面とまぜまぜを継続でき、超過分だけが優先順に従って自動投入される
- 21食完了または途中終了の結果に指定項目が表示される
- とことんの必要食材数が料理完成数に応じて増加し続け、レシピLvとボーナスはLv70で止まる
- 画面情報がSP幅で過度に縦長にならず、説明文なしで識別できる
