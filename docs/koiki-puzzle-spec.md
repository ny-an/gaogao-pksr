# お料理パズル ミニ版仕様

更新日: 2026-08-30

実装ページ: `koiki-puzzle.html`

## 1. 目的

ポケモンスリープの食材アイコン・レシピ構成・基礎エナジーを使った、短時間で遊べる料理パズルを試作する。

単なる4個消しではなく、以下をプレイヤーが自然に理解できることを重視する。

- 料理ごとに必要な食材と個数が異なる
- 食材には1個ごとの基礎エナジーがある
- 料理には料理エナジーがある
- 料理完成までに消した食材は、すべて追加食材エナジーになる

## 2. データの正本

ミニ版に複製した値は、既存の献立表データを正本とする。

- 食材名・食材基礎エナジー: `js/data/foods.js`
- 料理名・必要食材数・料理基礎エナジー: `js/data/dishes.js`
- 食材画像: `img/foods/svg/`

正本側の値が変更された場合、ミニ版のインラインデータも同期する。

## 3. 基本ルール

- 盤面は6列×6行の36マス
- 盤面には食材35個と操作アイコン1個を配置する
- 食材を1個タップすると、その食材と操作アイコンの位置が入れ替わる
- 入れ替えは隣接マスに限定せず、盤面上の任意の食材を選べる
- 同じ食材が縦または横に4個以上並ぶと消え、鍋へ入る
- 消去後は上の食材が落下し、空きマスへ新しい食材を補充する
- 補充後に4個以上そろった場合は、盤面が安定するまで連鎖する
- 得点可能な入れ替えがなくなった場合は、自動で盤面を混ぜる
- 手動の「まぜる」は1手消費する

## 4. 手数と終了条件

- 開始時の手数: 20手
- 食材との入れ替え: 1手消費
- 手動シャッフル: 1手消費
- 料理完成: 5手回復
- 手数の上限: 20手
- 盤面解決と料理完成処理の後、手数が0以下ならゲーム終了

## 5. エナジー計算

### 5.1 食材を消したとき

消した食材は、1個ごとの本来の食材基礎エナジーを追加食材エナジーとして料理完成まで蓄積する。この時点では累計エナジーへ加算しない。

```text
追加食材エナジー = Σ（消した個数 × 食材基礎エナジー）
```

連鎖倍率は掛けない。連鎖は、1手で複数回の消去と食材獲得ができること自体をメリットとする。

### 5.2 料理完成時

必要食材がそろったら、料理エナジーと、それまでに消した全食材の追加食材エナジーをまとめて累計へ加算する。

```text
完成料理エナジー = 料理エナジー + 追加食材エナジー
累計エナジー     = 累計エナジー + 完成料理エナジー
```

料理が完成しないままゲームが終了した場合、蓄積中の追加食材エナジーは累計へ加算しない。

### 5.3 追加食材

料理完成判定までに消した食材は、必要食材・余剰食材・レシピに不要な食材を問わず、すべて追加食材として扱う。

```text
追加食材エナジー = Σ（消した全食材の個数 × 食材基礎エナジー）
```

### 5.4 計算例

とくせんリンゴカレーは、とくせんリンゴ7個を必要とする。

```text
必要食材: とくせんリンゴ7個
料理エナジー: 748 エナジー
```

4個消しを2回行い、リンゴを8個消して料理を完成させた場合、8個すべてが追加食材になる。

```text
追加食材エナジー: 8個 × 90 エナジー = 720 エナジー
完成料理エナジー: 748 エナジー + 720 エナジー = 1,468 エナジー
```

## 6. 料理進行

ミニ版では次の8料理を固定順で出題し、8品目の次は1品目へ戻る。

| 順番 | 料理 | 必要食材 | 料理エナジー |
|---:|---|---|---:|
| 1 | とくせんリンゴカレー | とくせんリンゴ×7 | 748 エナジー |
| 2 | モーモーホットミルク | モーモーミルク×7 | 814 エナジー |
| 3 | ベイビィハニーカレー | あまいミツ×7 | 839 エナジー |
| 4 | マイペースやさいジュース | あんみんトマト×9、とくせんリンゴ×7 | 1,924 エナジー |
| 5 | サンパワートマトカレー | あんみんトマト×10、げきからハーブ×5 | 2,078 エナジー |
| 6 | ほっこりホワイトシチュー | モーモーミルク×10、ほっこりポテト×8、あじわいキノコ×4 | 3,181 エナジー |

料理が完成すると、鍋を空にして次の料理用の盤面を生成する。

## 7. 食材の出現制御

- 1つの盤面に出す食材は最大5種類
- 現在の料理に必要な食材を優先する
- 複数の必要食材がある場合、残り必要数の比率に応じて出現重みを変える
- 必要数を満たした食材の重みは下げる
- 必要食材以外も少量出し、追加食材と盤面上のノイズとして機能させる
- 初期盤面に完成済みの4個並びを作らない
- 少なくとも1つは得点可能な操作アイコンとの入れ替えを用意する

## 8. 表示仕様

- 上部に残り手数、累計エナジー、完成料理数を表示する
- 次の料理欄に料理名、必要食材、進捗を表示する
- 料理欄に「料理エナジー＋蓄積中の追加食材エナジー＝完成時のエナジー」を表示する
- 食材消去後に「食材名・個数×基礎エナジー＝追加食材エナジー」を表示する
- エナジーの単位は「E」と略さず「エナジー」と表示する
- 料理完成時は中央に料理、湯気、金色の放射光と星、最終エナジーのカウントアップを表示する
- ベストエナジーは `localStorage` に保存する
- 計算方式変更前の値と混在させないため、保存キーはバージョン2を使用する

## 9. 操作アイコン

- 提供されたプロフィール画像を使用する
- タイトル部分と盤面上の操作アイコンマスで同じ画像を使用する
- 画面上では固有名を付けず、単なる操作アイコンとして扱う
- 単体ページで表示を維持できるよう、画像はHTML内のData URLとして保持する

## 10. ミニ版では未対応

- 全料理からの選択・ランダム出題
- カレー・サラダ・デザートのカテゴリ選択
- 鍋容量
- レシピレベルボーナス
- フィールドボーナス
- イベントボーナス
- 大成功・日曜日補正
- 制限時間、デイリーミッション、ランキング
- 外部データ変更時の自動同期

## 11. 確認済み項目

- 8料理の必要食材数・食材基礎エナジー・料理基礎エナジーが正本データと一致する
- 盤面は36マスで、操作アイコンは常に1個だけ存在する
- とくせんリンゴ4個消去で追加食材360エナジーが蓄積される
- リンゴ8個でとくせんリンゴカレーを作ると、748＋720＝1,468エナジーになる
- 料理完成時に料理名、料理エナジー、追加食材エナジー、最終エナジーが表示される
- 390×1000のスマートフォン表示で主要操作が画面内に収まる
- ブラウザコンソールにエラー・警告がない
