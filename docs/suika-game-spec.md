# ごちそうできるかな！！ 仕様書

対象ファイル: [`suika-game.html`](../suika-game.html)（完全自己完結の1ファイルゲーム。外部依存は `img/foods/svg/` の食材アイコンと `img/icons/gaogaopuuun-koiki.png` のみ）

スイカゲーム風の落ちものパズル × ポケモンスリープの料理システム。
おなじ食材をくっつけて進化させ、料理をこなし、でんせつのごちそうをめざす。

- タイトル: **ごちそうできるかな！！**（koiki-puzzle「お料理できるかな！！」の姉妹作）
- サブタイトル: ベスト記録に応じた20段階のランク称号（後述）
- ファビコン: 🍲 / ヘッダーマスコット: gaogaopuuun-koiki.png（koikiと共通）

## 1. コアルール

- 盤面: ワールド座標 420×560。上部 y=92 に危険ライン（点線）
- 操作: 横スライドで狙い、離すと落下。**2秒以上ホールドで連続ドロップ**（0.5秒間隔）。
  短いタップは従来どおり「離した位置に1個」。キーボード（←→/スペース）対応
- 合体: おなじ食材同士が接触すると1段階上の食材に進化
- ゲームオーバー: 危険ラインから食材がはみ出したまま2.0秒経過
- ドロップ候補: チェーンの下位5種（出現率 22/22/20/18/18%）

### スコア（エナジー）
- 合体: **消した食材の基礎エナジー**（`js/data/foods.js` 準拠、リンゴ90〜シッポ342）
- コンボ: 1.2秒以内の連続合体で **コンボ数ぶんの倍率**（3コンボ=×3）
- シッポ×シッポ: 両方消滅して「👑でんせつのごちそう完成」**+55,555**（バカボーナス仕様）
- すべての獲得にフィールドボーナス（FB）%が乗る

## 2. 食材チェーン（毎ゲーム変動）

全19食材（foods.js のエナジー昇順）から、**丸くて個性の薄い11種のうちランダム4種を除外**して
15段階チェーンを構成する。序盤のサイズ差を保つための仕様（除外なしだと1段の成長が小さすぎて爽快感がない）。

- 常時登場（ピーキー枠・除外対象外）: リンゴ / ミルク / マメミート / ハーブ / キノコ / ながねぎ / カボチャ / シッポ
- 除外候補（opt）: 大豆 / ミツ / ジンジャー / トマト / エッグ / オイル / ポテト / コーン / カカオ / コーヒー / アボカド
- 半径: チェーン長に応じて 14→100 の前傾カーブを自動生成（`computeRadii`、指数0.85）

### シークレット
- 「食材のじゅんばん」ガイドに表示されるのは **ハーブ（pool idx 10）まで**。それ以降は点線の「？」枠
- シークレット食材は初生成時に「✨シークレット食材はっけん！」演出、**図鑑に永続記録**
- 図鑑（ガイドタップで開く）は**発見済みのみ表示**。未発見はシルエットも総数も見せない
- カボチャ到達で「🎃ずっしりカボチャかんせい！！」、シッポ到達で「✨シークレット！おいしいシッポ！！」

## 3. 物理エンジン（自前実装）

- **画像アルファチャンネル解析による複合コライダー**: 各食材SVGを96×96で読み、
  距離変換→貪欲法で最大6個の内接円にフィット（面積カバー90%で打ち切り）
- 単位形状（`UNIT_SHAPES`）を1回だけ解析し、チェーン位置の半径にスケールして使用
- 剛体力学: 質量=Σ円面積、慣性モーメント=平行軸定理で算出。接触点ごとに
  回転を含むインパルス解決＋摩擦（μ=0.35）。ながねぎは転がり、キノコはカサで立つ
- 形状の広がり上限は基準半径の1.65倍（`MAX_BOUND_RATIO`）、面積は円と同一に正規化（バランス維持）
- サブステップ4×ソルバー7反復。15体で約0.3ms/frame
- 画像未ロード時は円フォールバック。ロード完了時に既存の盤面食材へも形状を再適用
- デバッグ: コンソールで `window.__showColliders = true` で衝突円を可視化、
  `window.__suikaDebugHook = fn` で毎フレーム内部状態を受け取れる

## 5. ごちそう（ちゅうもん）システム

- スキル欄の下の「ごちそう」カードに実在料理が1件出題される（2行表示: 料理名＋素材アイコン進捗）
- **ドロップまたは合体で対象食材が盤面に生まれる**とカウントが進み、全部そろうと完成
- 報酬 = **料理の基礎エナジー**（`js/data/dishes.js` 準拠）× レシピLv補正 × FB
- ↻ボタンでいつでも別の料理に変更可（ノーペナルティ、進捗リセット）
- レシピは**48種**。必要数は実レシピの構成比を1ゲームで狙える量にミニ化（例: リンゴカレー=リンゴ×4）
- 出題条件: 必要食材がすべて今ゲームのチェーンに存在し、シークレット食材は**図鑑発見済み**の場合のみ
- **カボチャ・シッポを使う料理は出題しない**（`ORDER_MAX_POOL_IDX = 16` でガード）
  - 除外済み: あぶりテールカレー、ごろごろねっとうサラダ、ドキドキこわいかおパンケーキ、
    なりきりバケッチャシチュー、ヤドンテールのペッパーサラダ
- 報酬レンジ: とくせんリンゴカレー748 〜 とびはねるカレーうどん25,539

### レシピLv（永続）
- 完成するたびそのレシピのLv+1（**MAX 70**）。報酬 +5%/Lv
- 料理ノートの行背景がLv進行度のメーターになる（Lv70で満タン）。MAX時は金色「LvMAX」表示

### フィールドボーナス（FB・永続）
- **通算21品ごとに+5%、上限85%**（カンスト=357品）
- すべてのエナジー獲得（合体・料理・スキル・シッポ）に乗算
- 表示は料理ノートのヘッダーのみ（HUDには出さない）

### 料理ノート
- ごちそうカードをタップで開く
- FB現在値・通算料理数・次のFBまでの残り品数
- 全レシピ一覧（材料・Lv・FB込み報酬）。未発見シークレットを使うレシピは非表示
- ソート切替: エナジーじゅん / Lvじゅん

## 7. その他のUI・機能

- **きろく**（トップバー）: 合体・スキル・料理・ゲームオーバーの履歴（新しい順・最大200件・
  ゲーム内時刻とエナジー付き）。サマリーにエナジー/しんか回数/料理数/時間/FB
- **リザルト**: ためたエナジー（カンマ区切り）、ベスト更新バッジ（白ボーダー＋グロー、
  点滅はscaleでなくbox-shadowパルス=文字が滲まない）、最大食材、ランクアップ演出、𝕏シェア
- **途中セーブ**: 4秒ごと＋離脱時に自動保存。リロード時は「つづきから / さいしょから」の
  選択ポップアップ（選択待ちの間は自動セーブ停止 — 上書き事故防止）。
  **盤面（食材の配置）は保存・復元しない**（物理状態の完全復元は無理なので割り切り）。
  引き継ぐのはエナジー・食材チェーン・ごちそう進捗・スキル状態・きろく・プレイ時間
- トップバーは絵文字なしのひらがなボタン: 「おと」（ミュート時は取り消し線）/「きろく」/「あそびかた」
- **隠し機能**: ヘッダーのマスコットアイコンを1.5秒以内に5連打すると
  確認ポップアップ（「食材をシャッフルする？」シャッフル/やめる）のあと食材をシャッフル
  （除外セットを引き直して新ゲーム開始。バナー「🔀 食材をシャッフルした！」）。
  ゲーム途中に強制されないよう必ず確認を挟む
- **隠し機能3**: 画面左下の何もないところ（ビューポート左下30%の非UI領域）を3秒以内に10連打すると
  扇風機（ツムツム風）。盤面の全食材に上向き扇状のランダムな速度と回転を加えて吹き飛ばす。
  バナー「風がふいてきた！」。10回に1度（セッション内の使用回数が10の倍数）は「強風がふいた！」で
  威力1.9倍・拡散角広め・シェイク強め
- **隠しタイトル（4種）**: 連打系の隠し機能で獲得（`kabocha.hidden` にキー配列で保存）。
  通知はきろく履歴の1行だけで、タイトルいちらんの最下部に★行として獲得したものだけ表示される
  - かくしたもの みーつけた: どれかを初めて使ったとき
  - せんぷうき はっけん: 左下連打（扇風機）
  - がおぷん だいすき: マスコット（がおぷんアイコン）連打でシャッフル実行
  - びるどあっぷ はっけん: 右下連打（200個ふらせ）
  - いつでもげんき げんきえーる: げんきオールSのチップを30秒以内に100連打（使い切ったあとでも復活）
  - すきるめい まちがえた: エナジーチャージSのチップを10秒以内に20連打
- **隠し機能4**: げんきオールSを使い切ったあと、チップを100連打すると復活する（チップのフラッシュと
  効果音のみ）
- **隠し機能5**: エナジーチャージSのチップを20連打すると、バナー「⚡ エナジーチャージM？発動！」とともに
  7秒間チップ表記が「エナジーチャージM」になり、その間**りんごと牛乳だけ**が25個/秒で降り続ける。
  チップ背景のメーターが残り時間に合わせて減っていく。
  降った系譜は200個ふらせと同じ `cheat` 扱い（スコア等に入らない）、溢れ判定も同様に停止
- **隠し機能2**: 画面右下の何もないところ（ビューポート右下30%の非UI領域）を3秒以内に10連打すると
  「200個ふらせ」（バナー「なぜか食材がわいてきた！」）。通常ドロップと同じtier0〜4の食材200個を
  0.04秒間隔（25個/秒）で上からランダム投下し、物理で実際に合体していく様子を見せる。盤面の状態を問わずいつでも発動可
  （ゲームオーバー中と投下中を除く）。
  降らせた食材とその合体の系譜には `cheat` フラグが付き、**スコア・コンボ・注文進捗・
  スキルゲージ・履歴に一切入らない**（図鑑の発見だけ記録、シッポ×2の消滅ボーナスも無し）。
  投下中と終了後2.5秒は溢れ判定を停止し、その後は通常ルール（溢れていれば普通に終わる）
- **タイトル解放はリアルタイム**: ベストはプレイ中に随時更新され、しきい値到達の瞬間に
  「🎖 タイトルかくとく「◯◯」」バナー＋履歴記録＋サブタイトル更新。
  リザルトの「ベスト記録こうしん」判定はゲーム開始時点のベストとの比較
- あそびかた本文は適度に漢字（全ひらがなは読みにくかったため戻した）
- 効果音: WebAudio合成（ドロップ/合体音階/スキル/完成ジングル/ゲームオーバー）
- `prefers-reduced-motion` 対応、DPRスケーリング、スプライト事前レンダリング

## 8. 検討事項・設計判断の記録

### 採用した判断
- **複合円コライダー**: 凸多角形SAT案もあったが、円ソルバーの再利用で安定性と実装コストのバランスが良い
- **面積正規化＋広がり上限1.65倍**: 形状の個性（ながねぎの長さ）とゲームバランスの両立
- **料理の進捗カウントはドロップと合体の両方**: 合体のみだと最下位食材（リンゴ等）を使う
  レシピが完成不可能になるため
- **注文の食材はシークレット発見済み限定**: 図鑑コレクションが高額注文の解放条件になる周回動機
- **スコア=基礎エナジー / 料理=基礎エナジー / しきい値=ワカクサ準拠**: 数値の世界観をポケスリに統一
- **シークレットは名前も総数も伏せる**: シルエット表示案は実装後に廃止（「自分で見つけるから面白い」）
- **ランク称号は約200案ブレストから選抜**: 食材名そのままの初版はボツ。成長ストーリーの縦軸を持たせた

### ボツ案
- 鍋ゲージ（合体でスープが溜まる）: 戦略性がない
- 盤面食材の自動判定クッキング: 何が起きたか分かりにくい
- あぶりテールカレー（+30,000）: シッポ・カボチャは純粋な育成目標として温存
- タイトル案「めざせ でんせつ・◯◯」連結表記: くどい。称号単体表示に

### 既知の注意点・将来アイデア
- 危険ライン判定は「最上部の実コライダー」基準（topY）。細長い食材が立つと辛い（仕様）
- 押しっぱなし連続ドロップは鬼難易度と相性が悪い（すぐ溢れる）。緊急整地・序盤高速化用
- `EXCLUDE_COUNT`（現4）でチェーン長のチューニングが1行で可能
- 将来案: カボチャ料理の解禁トグル、称号のシェア文言反映、週替わり除外セット（シード共有）、
  ランク17以降の実測バランス検証（現状は理論値）
